Tietosuojaseloste

Voit harjoitella Ajokoulussa ilman käyttäjätiliä. Harjoitustiedot käsitellään omalla laitteellasi, eikä Ajokoulu lähetä niitä palvelimelle tai ylläpidä käyttäjärekisteriä. Ajokoulu ei käytä analytiikkaa, mainontaa tai kävijäseurantaa.

GitHub Pagesin tietoturvalokit

Kun käytät GitHub Pagesissa julkaistua Ajokoulua, GitHub kirjaa ja säilyttää IP-osoitteesi tietoturvaa varten. Tämä tapahtuu riippumatta Ajokoulun tallennusvalinnastasi. GitHub Pagesin kuvaus tietojen keräämisestä

GitHub kertoo omasta henkilötietojen käsittelystään, säilyttämisestä ja tietosuojaoikeuksien käyttämisestä tietosuojaselosteessaan. Henkilötietojen käsittelystä voi tehdä ilmoituksen tietosuojavaltuutetulle. GitHubin tietosuojaseloste · Tietosuojavaltuutetun toimisto

Eväste- ja tallennuskäytäntö

Ajokoulu käyttää HTTP-evästeiden sijaan selaimen paikallista tallennustilaa (localStorage). Sen ainoa tarkoitus on säilyttää edistymisesi seuraavaa käyntiä varten. Tallennus on oletuksena pois käytöstä ja käynnistyy, kun valitset Salli edistymisen tallennus. Traficomin ohje evästeistä ja vastaavista tekniikoista

Tallennuslupa on voimassa 180 päivää. Sen päätyttyä Ajokoulu poistaa tallennetun edistymisen, kun käytät sivustoa seuraavan kerran. Ilman tallennusta edistyminen näkyy saman käyttökerran ajan.

Voit perua suostumuksesi valitsemalla Tallennusasetukset Ajokoulun alatunnisteesta tai Edistyminen-näkymästä. Peruuttaminen poistaa Ajokoulun edistymistiedot selaimestasi. Voit poistaa tiedot myös selaimesi sivustoasetuksista.
